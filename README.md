# نور الكلمة — الموقع الرسمي

الموقع الرسمي لتطبيق نور الكلمة (Noor Al-Kalima).

## محتويات المستودع
- `index.html`: الموقع العربي الرسمي، بتصميم متجاوب ودعم RTL.
- `app-ads.txt`: ملف تمهيدي؛ يجب استبدال التعليق بسطر الناشر الحقيقي من AdMob قبل استخدامه للتحقق الإعلاني.
- `.github/workflows/pages.yml`: نشر تلقائي إلى GitHub Pages عند كل تحديث على فرع `main`.

## النشر
1. من إعدادات المستودع افتح **Settings → Pages**.
2. في **Build and deployment** اختر **GitHub Actions** كمصدر.
3. شغّل Workflow باسم **Deploy website to GitHub Pages** من تبويب Actions أو ادفع Commit جديدًا إلى `main`.
4. بعد نجاح النشر سيظهر رابط الموقع في **Settings → Pages**.

## ملاحظة AdMob
لا يوجد Publisher ID في المستودع حاليًا. لا تترك ملف `app-ads.txt` بالتعليق التمهيدي عند بدء إعداد AdMob؛ أضف سطر الناشر الرسمي كما يظهر في حساب AdMob.
